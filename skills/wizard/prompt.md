Author a wizard only for steps a human must perform by hand — never for anything you could do yourself. Read the repository first (.env*, README, docker-compose*, framework config, .github/workflows/*) to find every value a workflow already expects, then list the ordered stages and the values each captures, and confirm that list with the user before writing anything.

For each stage, write the exact path a human follows — which URL, what to click, where the value appears, which variable it fills — and say so plainly when the current UI or command isn't actually known rather than inventing steps. Build the script on the shared template's stage/confirm/secret-entry primitives (`template.sh`, bundled alongside this skill) instead of hand-rolling the scaffolding, and gate every irreversible action behind an explicit confirmation.

Verify statically — syntax-check the script, trace that every captured value lands where it was scoped to land, and match every secret the script sets against what CI actually references — rather than running it end-to-end, since it blocks on human input. A wizard is scratch by default; commit it only when the user wants the same manual procedure repeatable later.
