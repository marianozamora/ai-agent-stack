# wizard

Category: **operations**
Estimated context cost: **medium**

Stages: scope procedure → map each stage's journey → author the wizard → verify and hand off

Curated for AI Agent Stack from Matt Pocock's `wizard` skill. Generates a guided bash script (built on the bundled `template.sh`) for manual steps only a human can perform — provisioning, credentials, third-party dashboards, one-off migrations. Never invoked for steps the agent can do itself.
