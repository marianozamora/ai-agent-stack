For visually led web work (landing pages, marketing, portfolios, redesigns), design in images first when an image-generation tool is available:

1. Infer the site type and section count.
2. Generate one large, readable reference image per section, never one compressed board, plus detail images where text or components are too small. Regenerate an unclear section fresh instead of cropping an old image.
3. Analyze every image and extract the copy, type scale and weights, spacing, colors, buttons and component logic into a written spec.
4. Implement to match the references.

If no image tool is available, or the task is mainly technical (a bug fix, a precise existing design system), say so and code directly. Resolve ambiguity by preserving the visible language, layout and component family before inventing anything. Guard against drift: do not flatten distinctive sections into generic rows, compress spacing, nest cards in cards, crowd the first screen with pills and micro-labels, or let the hero exceed a clean two-line headline on a small laptop.
