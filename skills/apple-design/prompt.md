Make web UI feel physical, the way Apple's fluid interfaces do. Respond on pointer-down, continuously, with no artificial latency. Track drags 1:1 with pointer capture, respecting the grab offset.

Everything is interruptible: animate from the live on-screen value, never lock input, and use springs rather than CSS transitions for anything gesture-driven. Springs are critically damped by default (bounce 0, about 0.3-0.4s response); bounce about 0.2 only after a flick. Hand the release velocity to the spring, and project momentum (`current + (v/1000)*d/(1-d)`, d about 0.998) to choose the snap target. Enter and exit along the same path, anchor origins to the trigger, rubber-band at boundaries, and wait for about 10px of movement before committing a gesture direction.

Materials: translucent `backdrop-filter` chrome with content scrolling underneath, heavier material for structure, never light glass on light glass. Motion, sound and haptic feedback fire on the same frame, only where it matters. Honor `prefers-reduced-motion` (cross-fade), `prefers-reduced-transparency` and `prefers-contrast`. Type: size-specific tracking (tight display, near 0 body), leading inverse to size, `rem` spacing, system font first.
