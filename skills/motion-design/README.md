# motion-design

Category: **design**
Estimated context cost: **medium**

Stages: frequency gate → name the purpose → cheapest tool → gpu-only properties → easing and duration → interruption and exit → reduced motion and hover gating

Curated for AI Agent Stack from Emil Kowalski's `animate` skill. Builds an animation by making the decisions in the order that decides whether it feels right — including deciding not to animate. Distinct from `review-animations`, which judges motion that already exists.
