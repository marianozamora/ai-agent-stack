Archify is an external Node.js tool, not vendored into this stack: don't invent its behavior, don't skip straight to hand-drawn SVG. Before authoring a diagram, check for a local checkout — a path the user names, or `.tools/archify` — and use it if present; otherwise clone `https://github.com/tt-a1i/archify.git` at the pinned commit recorded in this skill's provenance, run `npm install` once inside it (requires Node >=18), and use that checkout for the session. Return NEEDS_HUMAN if neither Node nor network access is available.

Follow its own fast-authoring path once installed: choose one type — `architecture`, `workflow`, `sequence`, `dataflow`, or `lifecycle` — read only the matching schema and one matching example under its `schemas/`/`examples/`, and write a fresh candidate JSON with new IDs and this repository's own domain wording rather than copying the example's facts. Validate with `node bin/archify.mjs validate <type> <candidate.json> --quality showcase --json` after every edit; a passing showcase validation freezes the candidate. Deliver the final HTML with `node bin/archify.mjs deliver <type> <candidate.json> <output.html> --quality showcase --json`, and treat any non-zero exit as failure, never partial success.

Archify ships its own update-check that can contact a remote manifest. If it surfaces a notice, relay it to the user plainly and continue the task — never auto-update, and never treat the notice as consent to change the installed checkout. If the check cannot run, continue silently rather than blocking the diagram.
