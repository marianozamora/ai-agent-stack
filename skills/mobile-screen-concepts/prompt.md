Generate mobile app screen images, not code. First decide the platform mode (iOS-native, Android-native, or cross-platform neutral) and stay coherent; infer the app category and screen count, and generate every screen requested (an onboarding or auth flow is several screens, never one collage).

Lock a design bible before rendering: palette logic, type hierarchy, component family, surface and texture treatment, image art direction, icon style, device frame. Hold it across every screen; vary composition and emphasis, never identity. Order screens as a believable journey (onboarding, auth, home; cart, checkout, confirmation).

Each screen: safe areas respected, a clean first screen, short copy, comfortably readable text, real navigation, no website-in-a-phone layouts, no nested card clutter, no purple-blue startup palette or default icon sets, a subtle evenly padded phone mockup. Regenerate a weak or unreadable screen rather than accept it.
